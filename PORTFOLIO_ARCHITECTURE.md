## Scale privacy rule

Do not publish precise operational inventory counts for institutions, classrooms or transport assets.

Prefer qualitative scale language such as:

- multi-institution
- multi-classroom

Technical figures may be shown when they describe an engineering architecture rather than exposing operational inventory, and only when they materially improve the case study.

## Case-study model

A project is not just a card or technology list. Each project should explain:

1. **Problem** — what operational issue existed?
2. **My role** — what Pragalbh owned, designed, integrated or troubleshot.
3. **Constraints** — budget, existing equipment, reliability, people, legacy systems or deployment realities.
4. **Decisions** — architectural choices and trade-offs.
5. **Architecture** — a compact visual system diagram.
6. **Evidence** — repositories, implementation records, screenshots, field photographs or diagrams.
7. **Status** — production, active development, prototype architecture, applied system or field troubleshooting.

## Evidence and proof taxonomy

The portfolio must make the strength of each claim visible. Do not present every project as equally deployed or equally public.

Use these proof labels:

- **LIVE SYSTEM** — a publicly accessible working system.
- **LIVE + PUBLIC REPOSITORY** — a working public system with source/repository evidence.
- **PUBLIC REPOSITORY** — implementation or architecture is publicly inspectable in GitHub.
- **SOURCE-BACKED ARCHITECTURE** — supported by a proposal, implementation record or other internal source, but not presented as a completed deployment.
- **APPLIED INFRASTRUCTURE** — based on operational administration, implementation and troubleshooting work.
- **APPLIED SYSTEM DESIGN** — a system/data/integration architecture developed for active institutional work.
- **FIELD SYSTEM DESIGN** — engineering/design work tied to real physical deployment requirements; status must remain explicit.

The evidence layer currently uses a compact horizontal rail to avoid turning Recruiter View back into another long page.
