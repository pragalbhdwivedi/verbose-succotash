## Evidence states

- **LIVE SYSTEM** — publicly accessible working system.
- **LIVE + PUBLIC REPOSITORY** — working system plus inspectable source/workflow evidence.
- **PUBLIC REPOSITORY** — implementation or architecture can be inspected publicly.
- **SOURCE-BACKED ARCHITECTURE** — supported by a proposal or implementation record, but not claimed as completed deployment.
- **APPLIED INFRASTRUCTURE / SYSTEM DESIGN** — grounded in operational administration/integration work.
- **FIELD SYSTEM DESIGN / TROUBLESHOOTING** — tied to real physical requirements or diagnosis.

## Publication guardrails

1. Every asset must prove a specific claim.
2. Prototype work remains labelled prototype.
3. Do not claim Kritica Dwivedi's graphic/UI/UX/art-direction work as Pragalbh's professional discipline.
4. Do not expose exact protected operational counts.
5. Redact student/employee data, credentials, internal IP addresses, unnecessary serial numbers and sensitive security topology.
6. Use privacy-safe derivative diagrams when raw source material discloses too much.
